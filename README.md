# ponditech.com

Company website for Pondi Technologies (BRELA Reg. No. 723134, Dar es Salaam).

Plain static site, no build step: `index.html` plus favicons, `robots.txt`, `sitemap.xml`, `og-image.png`, `site.webmanifest`, `/img/` and `/video/`.
Hosted on Netlify (project `ponditech`), deployed automatically from `main`.

The contact form uses Netlify Forms: keep `data-netlify="true" netlify-honeypot="bot-field"` on the `<form>` tag.
